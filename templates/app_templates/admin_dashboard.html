Product Configuration

Products are automatically scraped from Stripe. Access the Stripe Dashboard to modify the product selection. Then either wait 10 minutes for the app to automatically update, or click the update products button.

Certain key parameters are taken from Stripe for each product. These include obvious ones like:

  • Product name
  • Description
  • Price
  • Whether the product is active (inactive products are not displayed)

Additionally, some metadata tags (also from Stripe) are used by this application:

  • show-on-dancetech: Must be set to true for the product to display in the app.
  • requires-roles: Comma-separated list of roles (case-insensitive) to restrict product access.
  • show-preview: Set to true to allow users without sufficient permissions to see a preview of the product.
  • sort-level: Set to an integer to change the order with which the products appear. Smaller numbers appear first. Products with the same sort level are sorted alphabetically.
