Product Configuration

Products are automatically scraped from Stripe. Access the Stripe Dashboard to modify the product selection. Then either wait 10 minutes for the app to automatically update, or click the update products button.

Certain key parameters are taken from Stripe for each product. These include obvious ones like:

  • Product name
  • Description
  • Price
  • Whether the product is active (inactive products are not displayed)

Additionally, some metadata tags (also from Stripe) are used by this application:

  • {{ stripe_keys.show_on_dancetech }}: Must be set to true for the product to display in the app.
  • {{ stripe_keys.requires_roles }}: Comma-separated list of roles (case-insensitive) to restrict product access.
  • {{ stripe_keys.show_role_preview }}: Set to true to show a greyed-out preview to users who do not yet have the required roles. They still cannot buy it.
  • {{ stripe_keys.show_time_preview }}: Set to true to show a greyed-out preview before a one-shot window starts. After the window ends, the product stays hidden. Weekly windows show that preview whenever the product is not currently for sale.
  • {{ stripe_keys.category }}: Optional group name. Products that share the same value appear together in a collapsible section on Check In. Omit to leave the product ungrouped at the top of the page.
  • {{ stripe_keys.category_sort_level }}: Where that section sits on the page, relative to other sections. Smaller numbers appear first (default 0). This does not order products inside the section. Put the same value on every product in the group; if they disagree, the highest number wins, so an omitted tag (default 0) does not override a value set on other products. Sections with the same level are sorted alphabetically by category name.
  • {{ stripe_keys.sort_level }}: Where this product sits inside its section (or among ungrouped products if it has no category). Smaller numbers appear first (default 0). Products with the same sort level are sorted alphabetically by product name. This does not move the section.
  • Example: two products tagged {{ stripe_keys.category }}=Lessons with {{ stripe_keys.category_sort_level }}=1 make a Lessons box. A Socials box with {{ stripe_keys.category_sort_level }}=2 appears below it. Inside Lessons, Beginner at {{ stripe_keys.sort_level }}=0 appears above Advanced at {{ stripe_keys.sort_level }}=1.
  • {{ stripe_keys.show_timezone }}: IANA timezone for the windows below. Defaults to America/New_York.
  • {{ stripe_keys.show_interval }}: One-shot windows, comma-separated. Same day: 2026-08-14 18:00/22:00. Multi-day: 2026-08-14 18:00/2026-08-15 01:00.
  • {{ stripe_keys.show_weekly }}: Recurring weekly windows, comma-separated, e.g. Thu 18:00-23:00, Fri 18:00-23:59.
  • If both interval tags are omitted, the product is always shown (same as today). A typo hides the product (fail closed) and the parse error appears on this page.
